# Anons Sistemi (GitHub Pages)

## Yukleme
1. Public bir GitHub reposu olusturun, bu klasordeki dosyalari yukleyin (index.html, sounds.json, sounds/).
2. Mp3 dosyalarini `sounds/` klasorune koyun. Dosya adi = buton adi (namaz.mp3 -> "Namaz", mesai_bitti.mp3 -> "Mesai bitti").
3. Settings > Pages > Branch: main > Save. Adres: https://KULLANICIADI.github.io/REPOADI/

## Kullanim
- PC: https://KULLANICIADI.github.io/REPOADI/?pc  -> PIN girin -> "Baslat". Sayfa acik kalmali.
- Telefon: https://KULLANICIADI.github.io/REPOADI/ -> ayni PIN -> kumanda acilir.
- Ust: mikrofon (basili tut = canli konus), yaninda "Durdur". Alt: ses butonlari.
- PIN iki cihazda da ayni olmali. PIN degismedigi surece baglanti ayni kalir, bir kez girmeniz yeter.

## Notlar
- Buton listesi GitHub'dan otomatik okunur. Okunamazsa sounds.json kullanilir.
- 6 haneli veya daha uzun bir PIN secin.
